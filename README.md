# 📱 HHSR Application


## ✨ Features
- User Login
- Order Submit/View
- Guest Order Submit/View
- Edit Resident
- View Kitchen Summary
- View Order Report
- View Charges Report
- View/Print Order Receipt

## 🛠 Technology Stack
- **Language:** Swift
- **Framework:** UIKit
- **IDE:** Xcode
- **Networking:** Alamofire
- **JSON Parsing:** SwiftyJSON


## 📂 Project Structure

- `SplashScreenVC.swift` – Main launch screen logic
- `Models/` – Data models
- `Utilities/` – App utility classes
- `Images/` – Images
- `Custom Cells/` – TableView and CollectionView Cells
